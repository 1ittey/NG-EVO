# NG-EVO Changelog

All notable changes to NG-EVO will be documented here.

## [1.0.2] — 2026-10-03

**Save Safety:** Save Safe

### Changed

- Reduced breast and butt size on NPCs for a more balanced appearance.
- Slightly increased interior brightness across the game.
- Added new PBR upper class furniture from Sothasimp's latest furniture mod.

### Removed

- Removed Medieval Candlehorns and Sconces due to an issue causing unusual flame flickering.

### Fixed

- Added Candle Lag Fix to address candle lighting performance and responsiveness issues.

## [1.0.0] — Initial Release

**Release Status:** Public Release

### Added

- Initial public release of **NG-EVO — Next Generation Enderal Visual Overhaul**
- Complete visual overhaul for Enderal: Forgotten Stories Special Edition
- PBR-focused texture and material improvements
- Community Shaders-based visual enhancements
- Improved lighting and weather
- Enhanced landscapes, mountains, vegetation, and environmental details
- Improved distant terrain and object rendering
- Custom compatibility patches and fixes
- Generated LODs and visual optimization
- Parallax and complex-material support where appropriate
- Enderal-specific visual fixes and adjustments
- Curated visual consistency across the modlist

### Testing

- Completed beta testing with real-world installations and gameplay sessions.

### Distribution

- Initial public distribution through Wabbajack.

### Post-Release Fixes

- Fixed an issue where the game could fail to launch because the required Game Output folder was missing.
- Updated the Wabbajack configuration to ensure Game Output is included correctly during installation.
